Sistema de cartelera de cine

Hecho en C#. Su función es permitir administrar películas que se encuentran registradas, 
utilizando una base de datos en SQL Server.

Instrucciones

1. Ejecutar el archivo `CarteleraDB.sql` para crear la base de datos.
2. Abrir el proyecto en Visual Studio.
3. Verificar la conexión a SQL Server LocalDB.
4. Ejecutar el programa con `Ctrl + F5`.

Opciones del sistema

- Registrar películas.
- Listar películas.
- Buscar por ID.
- Actualizar precios.
- Eliminar películas.
